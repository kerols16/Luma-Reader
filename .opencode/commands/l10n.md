---
description: Add localized strings to en and ar ARB files
---

Add the strings described here:

$ARGUMENTS

For every key:

1. Add it to `lib/core/l10n/app_en.arb` with an English value.
2. Add the same key to `lib/core/l10n/app_ar.arb` with a natural Arabic value.
3. Add `@key` metadata (description, placeholders) to the English ARB only.
4. Use ICU plurals for counts; Arabic needs zero/one/two/few/many/other.

Then run `flutter gen-l10n` and `flutter analyze`. Report the keys added and any
errors. Do not hardcode fallback strings in widgets.
